# FinanceOS

FinanceOS é um ERP financeiro pessoal, construído como monorepo, com o objetivo de substituir o uso de planilhas por uma plataforma centralizada e automatizada de gestão financeira.

O projeto é desenvolvido de forma incremental, guiado por EPICs e com forte disciplina de escopo e documentação, envolvendo tanto colaboração humana quanto de agentes de Inteligência Artificial.

Para a visão completa do produto, consulte [PROJECT_MASTER_PLAN](docs/PROJECT_MASTER_PLAN.md).

---

## Objetivo

Centralizar receitas, despesas, contas, cartões, patrimônio e investimentos em uma única plataforma, com automação e integridade de dados como prioridades.

---

## Estado Atual

O projeto encontra-se em desenvolvimento.
