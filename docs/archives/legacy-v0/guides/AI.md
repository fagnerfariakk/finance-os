# Objective
Define how AI is used safely.

## Responsibilities
- Suggest categories
- Detect duplicates
- Identify merchants
- Generate insights

## Restrictions
- Never modify data automatically.
- Always provide confidence score.
- Always provide justification.

## Logging
Store prompts, model, execution time and result metadata when applicable.
