# Coding Standards

## General
- TypeScript strict
- No `any`
- ESLint + Prettier

## Design
- SOLID
- Clean Architecture
- DRY
- KISS

## Naming
- PascalCase: Classes
- camelCase: variables/functions
- UPPER_CASE: constants

## Functions
- Single responsibility
- Small and testable

## Commits
Conventional Commits only.

## Reviews
Prefer refactoring over duplication.
