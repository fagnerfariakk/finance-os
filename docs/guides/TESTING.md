# Testing Strategy

## Levels
- Unit
- Integration
- End-to-End (future)

## Tools
- Vitest
- Supertest
- Playwright (future)

## Rules
- Every Service must have unit tests.
- Bugs require regression tests.
- Mock external integrations.
- Tests must be deterministic.

## CI
Build, lint and tests are mandatory before merge.
